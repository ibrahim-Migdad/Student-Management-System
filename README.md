# Student Management System

A simple Python-based Student Management System created to practice programming fundamentals and build a practical project.

## Features

* Add student information
* View student information
* Search for students 
* Manage student records
* Simple menu-based interface

## Technologies Used

* Python

## Purpose

This project was built as part of my journey learning Python and software development. It helped me practice programming concepts such as variables, functions, conditionals, loops, and data management.

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the Python program.
